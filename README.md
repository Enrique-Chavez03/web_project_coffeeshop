# Triple Espresso

# Descripcion del proyecto

El Proyecto 4 consiste en crear una página web completa para una cafetería desde cero. Esta página web incluye varias secciones funcionales:

Encabezado (Header): Con navegación y branding de la cafetería
Sección de Recetas: Donde se muestran videos embebidos de YouTube con recetas
Sección de Reservas: Un formulario interactivo para que los clientes puedan reservar mesas
Sección de Menú: Para mostrar los productos de la cafetería
Pie de página (Footer): Con información de contacto y enlaces adicionales
Tecnologías utilizadas:

HTML5: Para la estructura semántica de la página
CSS3: Para el diseño y estilos visuales
Flexbox: Para el diseño responsivo y alineación de elementos
Google Fonts: Para tipografías personalizadas (Inter y Noto Serif)
iframes: Para embeber videos de YouTube
Formularios HTML: Para la funcionalidad de reservas
Git y GitHub: Para control de versiones y colaboración
Metodología BEM: Para organización de código y archivos CSS
Características especiales del proyecto:

Un proyecto completamente desde cero (sin codigo inicial)
Se implementa organización de archivos según BEM
Se incluye contenido multimedia embebido
Formularios funcionales con validación
Diseño responsivo para diferentes tamaños de pantalla
